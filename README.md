🍳 Recipe AI
Recipe AI is an AI-powered recipe assistant that helps users discover recipes based on the ingredients they already have.
Users can enter their available ingredients and preferences, and the application uses an LLM to generate suitable recipes with ingredients, cooking steps, preparation time, and difficulty level.
✨ Features
🤖 AI-powered recipe generation
🥔 Generate recipes from available ingredients
🥗 Vegetarian and other preference-based suggestions
📝 Detailed ingredients and cooking instructions
⏱️ Cooking time and difficulty level
💬 Simple recipe-focused interaction
💾 Store generated recipes in MongoDB
📦 Structured JSON responses from the AI
